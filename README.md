# Registro de Libros MVC

Proyecto simple MVC para registrar libros usando:
- Node.js
- Express
- MariaDB

## Archivos clave
- `app.js`: aplicación Express principal
- `models/bookModel.js`: modelo MariaDB
- `controllers/bookController.js`: controlador
- `views/index.ejs`: vista principal
- `static/style.css`: estilos CSS
- `database/schema.sql`: script de creación de base de datos

## Requisitos
- Node.js
- MariaDB

## Instalación
1. Crear la base de datos `library` en MariaDB o ejecutar `database/schema.sql`.
2. Instalar dependencias:
   `npm install`
3. Iniciar la aplicación:
   `npm start`

## Ejecución rápida
- Con Node: `npm start`
